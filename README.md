# CI/CD Pipeline Project

## Project Name
OpenShift CI/CD Pipeline Automation

## Project Description
This project demonstrates Continuous Integration and Continuous Deployment (CI/CD) using GitHub Actions, Tekton and Red Hat OpenShift.

## Technologies Used
- GitHub
- GitHub Actions
- Python
- Flake8
- Nose
- Tekton
- Docker / Buildah
- Red Hat OpenShift

## Pipeline Steps
1. Cleanup
2. Git Clone
3. Code Linting using Flake8
4. Unit Testing using Nose
5. Build application image using Buildah
6. Deploy application on OpenShift

## Objective
To automate application testing, container image building and deployment using CI/CD tools.
